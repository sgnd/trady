## Trust boundaries checked

| Boundary | Lower-trust side | What protects it | Result |
|---|---|---|---|
| Vault values versus an AI agent | The agent running trady | Values only from `--from-env`; `--reveal` and typed input refused for agents | Holds, with the limit in N2 |
| The sealed store on disk | Anyone who can read `~/.trady` | AES-256-GCM per row; ID, type and version bound as additional data; HKDF key; random nonces; files 0600, folder 0700 | Holds |
| Media and transcript content | The author of a recording | Paths made absolute before reaching ffmpeg; captions written to a private temp folder | F2 fixed |
| Files in the current folder | The author of a folder you run trady in | None before the fix | F1 fixed |
| Network | Remote parties | No network code in the binary, guarded by a test | Holds |
| Release download | Whoever can change a release asset | TLS only | N3 |

## Findings

| ID | State | Severity | Summary | Fix | Test |
|---|---|---|---|---|---|
| F1 | Confirmed, fixed | Medium | `trady guide install` read `skills/trady/SKILL.md` from the current folder and installed it as a global Cursor skill. Run inside a cloned repo, that repo's author could plant instructions for your AI agent. | The skill now comes only from text built into the binary. | `TestSkillBodyIgnoresCurrentFolder` |
| F2 | Confirmed, fixed | Low | Caption text went to libass unchanged, so words in a recording could carry `{\...}` or `<font>` tags that restyle or hide the captions. | `{ } < > \` are dropped from caption text. | `TestSRTDropsStyleTags` |
| N1 | Fixed without validation | None | On macOS, the new store key is passed to `/usr/bin/security` as a command line argument. Whether another local process can read it depends on macOS process-argument rules, which the repository cannot show. | To check: from another user account, read the arguments of a running `security add-generic-password`. Fixed anyway: the key now goes on stdin to `security -i`, as komando does. | `TestKeychainKeyNotInArguments` |
| N2 | Fixed (macOS, Linux) | None | trady treats a caller as an AI agent when `TRADY_AGENT=1` or stdin is not a terminal. An agent that runs trady in a pseudo-terminal without that variable is treated as a person and can use `secret show --reveal`. | `--reveal` now asks in a window (osascript, zenity). Windows stops with `NEEDS_PERSON` (plan item 12d). | `TestRevealAsksInWindow` |
| N3 | Deferred to milestone 7 | None yet | `install.sh` installs the release asset without checking a checksum. No release exists yet, so nothing can be downloaded today. | Publish checksums with releases and check them in `install.sh`. | With milestone 7 |

## Checked and not a finding

- Crypto in `internal/sealrow`: AES-256-GCM, 12-byte random nonces, row identity in the additional data, key from HKDF-SHA256.
- File modes: the store and key file are 0600 in a 0700 folder; temp audio and caption files are in `os.MkdirTemp` folders (0700).
- Argument injection into ffmpeg and whisper-cli: every path is absolute, and no value from a recording becomes a flag.
- Clips written with `--out` outside `~/.trady` get the default file mode. That folder is the user's own choice.
- Two trady processes writing at once can lose one update. That affects data integrity, not a trust boundary.
